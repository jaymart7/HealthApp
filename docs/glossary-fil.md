# Filipino glossary

Every `values-fil/strings.xml` follows this list, so one term reads one way on every screen. A
new English string gets its Filipino here first if it brings a new term. `./gradlew
checkTranslations` holds keys, placeholders and plurals; this file holds the words.

**Not yet reviewed by a native speaker.** Written with the app, from this list.

## Register

- Modern Filipino as Google's own Android apps write it: everyday words, English loanwords where
  Filipinos actually use them (calories, carbs, streak, badge, barcode), never deep Tagalog a
  reader would have to look up.
- Second person, warm and short: *mo / ka / iyong*. Never *po* — the app is a buddy, not a clerk.
- Buttons and actions are imperatives. A borrowed verb takes the hyphenated **I-** prefix
  (*I-save, I-log, I-edit, I-scan, I-export, I-import, I-share, I-reset, I-undo*); a native verb is
  its plain imperative (*Idagdag, Tanggalin, Burahin, Tingnan, Kunin, Piliin, Simulan, Tapusin,
  Kanselahin, Subukan ulit, Bumalik, Laktawan, Isara, Buksan, Palitan, Itago*).
- A label short in English stays short. Where Filipino runs long, pick the shorter honest word
  rather than letting a chip or a tab wrap.
- Numbers, `%`-placeholders and unit symbols stay exactly where the sentence needs them; word
  order may move around them, positional placeholders (`%1$s`) make that safe.
- Plurals: Filipino nouns do not inflect, so `one` and `other` are usually the same sentence —
  both still carry the `%d`.

## Never translated

FitPulse · Health Connect · Google Health · Google · Gemini · Wear OS · Play · the mascot names
(Rui, Gel, Mart, Alo, Lala) · unit symbols (kg, lb, cm, in, kcal, g, mg, µg, IU, ml, L, fl oz,
bpm, mmHg, h, m, %) · BMI · AI · CSV · JSON · PNG.
